2. ARCHITECTURAL CONTRACTS IMPLEMENTED
- Overlay Contract:
  * src/lib/overlay/types.ts: OverlayState { enabled, visible, noteId, minimized, permission: unknown|granted|denied|unsupported }, OverlayCommand.
  * src/lib/overlay/controller.ts: State machine managing show, hide, toggle, minimize, restore, close (non-destructive), and requestPermission.
  * src/lib/overlay/note-sync.ts: Bidirectional broadcast sync via BroadcastChannel and localStorage events.
- Platform Bridge:
  * src/lib/platform/capabilities.ts: Detects Web vs Desktop-Linux (Tauri) vs Android with clear capability flags and explanations.
  * src/lib/platform/native-bridge.ts: Pluggable NativeBridge interface with WebFallbackBridge, TauriDesktopBridge, and AndroidNativeBridge.
- Notes Store:
  * src/lib/notes/store.ts: Offline-first localStorage persistence ('stick_up_notes_v1'), getOverlayNote, applyOverlayPatch, createOverlayNote, createNote, updateNote, deleteNote, togglePin, toggleArchive.
- User Interface:
  * src/components/Header.tsx: Search, Freeform Canvas vs Responsive Grid view toggle, filter pills, new note, quick overlay toggle, settings.
  * src/components/StickyNote.tsx: Draggable paper card, header tape, checklists, theme picker, pin, float overlay button, archive, delete.
  * src/components/FreeformCanvas.tsx: Draggable canvas with coordinate persistence and z-index management.
  * src/components/GridView.tsx: Responsive masonry/grid layout.
  * src/components/SettingsModal.tsx: Dedicated Overlay section showing permission status, platform capabilities, browser notice, note selection, and overlay commands.
  * src/views/FloatingOverlayView.tsx: Dedicated frameless always-on-top window view with draggable header, in-place edit, quick capture (+), minimize to bubble, restore, open main board, and non-destructive close.

10. Store Reactivity, Freeform Dragging & Live Interaction Fix (2026-10-30)
- Root Cause Analysis:
  * In-place mutation bug in NotesStore: `store.updateNote`, `store.createNote`, and `store.duplicateNote` mutated `this.notes` in place and emitted the same array reference. React's `useState` bailed out (`Object.is(prev, next)` was true), preventing re-renders on keystrokes, checklist clicks, and dragging.
  * Card drag limitation: Only the small 28px tape handle was listening for drag events, and CSS `transition-all 200ms` caused drag positions to lag behind the cursor.
- Architectural Fixes:
  * Refactored NotesStore to guarantee immutable state updates (`this.notes.map`, `[newNote, ...this.notes]`), and emit cloned snapshots to all subscribers.
  * Made checklist items fully editable input rows instead of static text spans.
  * Allowed dragging across the full note card, header bar, and tape handle (bypassing inputs, textarea, and buttons).
  * Removed transition latency during canvas mode for snappy, 60fps real-time dragging.
  * Added canvas double-click note creation to spawn notes directly on the spot at click coordinates.
  * Defaulted main view to Canvas mode so notes float freely immediately upon launch.
- Verification: 33 Vitest unit tests pass across 7 test suites, TypeScript passes with 0 errors, Vite build succeeded, and preview server restarted on port 4173.
