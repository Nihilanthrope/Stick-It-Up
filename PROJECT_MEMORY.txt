================================================================================
STICK UP NOTES - PROJECT MEMORY & ARCHITECTURE STATUS

1. PROJECT SUMMARY
- Repository: /home/nihilanthrope/github/Stick-Up-Notes
- Product: Stick Up Notes (Native App)
- Design: Cream × Crimson default palette with paper sticky-note physical feel.
- Stack: React 18, TypeScript, Tailwind CSS, Lucide icons, Vitest, Tauri 2 (Desktop Linux), Native Android Overlay (SYSTEM_ALERT_WINDOW).

2. ARCHITECTURAL CONTRACTS IMPLEMENTED
- Overlay Contract:
  * src/lib/overlay/types.ts: OverlayState { enabled, visible, noteId, minimized, permission: unknown|granted|denied|unsupported }, OverlayCommand.
  * src/lib/overlay/controller.ts: State machine managing show, hide, toggle, minimize, restore, close (non-destructive), and requestPermission.
  * src/lib/overlay/note-sync.ts: Bidirectional broadcast sync via BroadcastChannel and localStorage events.
- Platform Bridge:
  * src/lib/platform/capabilities.ts: Detects Web vs Desktop-Linux (Tauri) vs Android with clear capability flags and explanations.
  * src/lib/platform/native-bridge.ts: Pluggable NativeBridge interface with WebFallbackBridge, TauriDesktopBridge, and AndroidNativeBridge.
- Notes Store:
  * src/lib/notes/store.ts: Offline-first localStorage persistence ('stick_up_notes_v1'), getOverlayNote, applyOverlayPatch, createOverlayNote, createNote, updateNote, deleteNote, togglePin, toggleArchive.
- User Interface:
  * src/components/Header.tsx: Search, Freeform Canvas vs Responsive Grid view toggle, filter pills, new note, quick overlay toggle, settings.
  * src/components/StickyNote.tsx: Draggable paper card, header tape, checklists, theme picker, pin, float overlay button, archive, delete.
  * src/components/FreeformCanvas.tsx: Draggable canvas with coordinate persistence and z-index management.
  * src/components/GridView.tsx: Responsive masonry/grid layout.
  * src/components/SettingsModal.tsx: Dedicated Overlay section showing permission status, platform capabilities, browser notice, note selection, and overlay commands.
  * src/views/FloatingOverlayView.tsx: Dedicated frameless always-on-top window view with draggable header, in-place edit, quick capture (+), minimize to bubble, restore, open main board, and non-destructive close.

3. DESKTOP LINUX LAYER (TAURI 2)
- Configuration: src-tauri/tauri.conf.json
  * Window 'main': standard 1100x780 board window.
  * Window 'overlay': frameless, transparent, always-on-top, 320x380 floating sticky note window.
- Rust Handlers (src-tauri/src/lib.rs):
  * show_overlay_window(note_id)
  * hide_overlay_window()
  * set_overlay_minimized(minimized)
  * open_main_window()
- Arch Linux Verification:
  * WebKit2GTK 4.1 required for linking GTK3 webview on Arch Linux. If not installed on the system, cargo check reports missing webkit2gtk-4.1.pc. Documented clearly for runtime execution.

4. ANDROID NATIVE LAYER
- Implementation:
  * android/app/src/main/AndroidManifest.xml: SYSTEM_ALERT_WINDOW, FOREGROUND_SERVICE permissions.
  * OverlayPermissionHelper.kt: Checks Settings.canDrawOverlays(context) and builds Settings.ACTION_MANAGE_OVERLAY_PERMISSION intent.
  * StickUpOverlayService.kt: Android Service utilizing WindowManager with TYPE_APPLICATION_OVERLAY, touch drag listener, full sticky note view, minimized floating bubble, in-place editing, quick capture, and main app launch.
  * StickUpNativeBridgeInterface.kt: @JavascriptInterface exposing bridge methods to the webview as window.__STICK_UP_ANDROID_BRIDGE__.
  * MainActivity.kt: Configured with WebView and bridge injection.
- Verification:
  * Gradle build configuration created with Android SDK 35 and Kotlin 2.0.

5. NON-DESTRUCTIVE CLOSE VERIFICATION
- The contract explicitly guarantees that closing/hiding an overlay window NEVER deletes the note. Verified via automated tests in src/test/overlay-controller.test.ts and src/test/overlay-note-sync.test.ts.

7. Native overlay hardening (2026-10-30)
- Android overlay was changed from a second native note editor to the shared React FloatingOverlayView inside a WindowManager WebView. This removes the previous synchronization split and keeps localStorage/notes/themes/checklists in one model.
- Android overlay service is foreground-capable, uses SYSTEM_ALERT_WINDOW, supports minimize/restore/hide, and exposes native titlebar movement through the JS bridge.
- Linux Tauri overlay now includes a Hyprland-specific runtime integration: when HYPRLAND_INSTANCE_SIGNATURE is present it floats, pins, and raises the overlay by title, then applies the intended 320x380 size.
- Empty Tauri icon placeholders were replaced with valid RGBA PNG icons; invalid .icns/.ico placeholders were removed from bundle configuration.
- Added @tauri-apps/cli 2.12.4 and an Android Gradle wrapper using Gradle 9.8.2.
- Verification: 17 Vitest tests pass; TypeScript typecheck and Vite production build pass; Tauri cargo check passes; Tauri release binary and deb/rpm bundles build (AppImage bundling can still require external AppRun/linuxdeploy downloads); Android debug APK builds and was installed successfully to the connected Android 16 device.
